# Studymon

A Godot 4.7 study game: raise an AI companion through tap-care, then turn reviewer material into a
gym campaign of Identification and Essay battles.

**Read [`docs/rules.md`](docs/rules.md) before changing anything.** It is short and it is the
contract. Then [`docs/README.md`](docs/README.md) for the index, and
[`docs/tasks.md`](docs/tasks.md) if you are picking up in-flight work.

**Never stage, commit, amend, push or merge — the maintainer owns the repository's history.**
Read-only `git status` / `diff` / `log` / `show` are fine. Hand off with a summary and a proposed
commit message instead.

The approach is Ponytail — the smallest complete change that works. It ships as a project skill at
[`.opencode/skills/ponytail/SKILL.md`](.opencode/skills/ponytail/SKILL.md); do not install it
globally.
